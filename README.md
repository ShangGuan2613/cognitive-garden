# 认知园

一座缓慢生长的理解树，不是课程。

个人认知展示与迭代站（Domain → Point），基于 [itshen/learn-ai](https://github.com/itshen/learn-ai)（**AGPL-3.0**）改编：保留 Wiki 学习壳与 `course-data` 结构，去掉助教/证书/打卡/营销漏斗，换成杂志风高对比审美与可修订的主张点。

## 在线

GitHub Pages 启用后见仓库 Settings → Pages（或本 README 更新后的 URL）。

## 本地

```bash
cd docs
python3 -m http.server 8788
```

打开 <http://127.0.0.1:8788/>。

## 改内容

只改 **`docs/course-data.js`**，并同步 `docs/points/<id>.html`。详见 `FORK.md`。
